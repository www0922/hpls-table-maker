## 涉及文件

| 文件 | 代号 | 说明 |
|------|:--:|------|
| `江西华大T7+上机-PE150-*.xlsx` | A表 | 上机数据源（input_data/，含数字命名的 sheet） |
| `PE150_pooling模板表.xlsx` | 模板 | 输出模板（根目录，只读，仅含 A 数据 sheet） |

**自动发现**：按关键词匹配（"上机"/"质检"/"自建库"），排除临时文件 `~$`，多文件时报错。

**输出命名**：`{当天日期}文库pooling表T7+PE150.xlsx`，例如 `20260806文库pooling表T7+PE150.xlsx`。

## 执行顺序

```
clear_pooling → step1_migrate → step2_lookup → step3_group_sort
→ step4_formula → step5_lane → step6_t7_prepare → step7_offline_stats
→ format_font
```

| 步骤 | 脚本 | 功能 |
|:--:|------|------|
| 0 | `clear_pooling.py` | 复制模板、动态同步 sheet、清空数据 |
| 1 | `step1_migrate.py` | A表 → B表 数据迁移 |
| 2 | `step2_lookup.py` | C表/D表 → B表 查找填充（含 R/S 列） |
| 3 | `step3_group_sort.py` | 分组、组内 B列排序、均匀拆分 |
| 4 | `step4_formula.py` | E/F 公式、重分组、汇总行、10nM 前置排序 |
| 5 | `step5_lane.py` | Lane 编号、合并、框线、颜色标记、文库环化 |
| 6 | `step6_t7_prepare.py` | T7+制备 数据填充与公式 |
| 7 | `step7_offline_stats.py` | 下机数据统计模版 生成 |
| 8 | `format_font.py` | 字体、行高、数字/百分比格式、列宽、框线、条件格式 |

## 步骤零：清空模板 & 动态 Sheet 同步

**脚本：** `clear_pooling.py`

1. 调用 `config.prepare_output()` 复制模板到 `output_result/`
2. 调用 `config.sync_b_table_sheets(wb)` 动态调整数据 sheet
3. 清空所有工作表第 2 行起的数据和合并单元格，保留表头

### Sheet 映射规则

A 表 sheet 名按 **数字优先** 映射为字母：

| A表 | → | B表 |
|:--:|:--:|:--:|
| 1 | → | A |
| 2 | → | B |
| 3 | → | C |
| ... | → | ... |

### 动态同步逻辑

- 模板仅保留一个数据 sheet `A`（含完整表头及 R/S 列），其余 sheet 均从 A 派生
- **缺失的数据 sheet**：优先用多余 sheet 重命名，其次从现有 sheet 复制
- **多余的数据 sheet**：直接删除
- **非数据 sheet**（文库环化、T7+制备、下机数据统计模版、B1-B3）保留不动
- 通过 `ensure_columns={18: '人工检测结果', 19: '人工备注'}` 确保所有数据 sheet 的 R/S 表头完整

## 步骤一：数据迁移（A表 → B表）

**脚本：** `step1_migrate.py`

**操作对象：** 所有数据 sheet（动态确定）

A 表使用 `data_only=True` 模式读取，按行一一对应迁移。

### 文库编号解析（优先级从高到低）

| 优先级 | 来源 | 说明 |
|:--:|------|------|
| 1 | A表 B/C列合并格 | 池文库编号 |
| 2 | A表 C列 | HaploX编号 |
| 3 | A表 D列 | 样本名称（前两者为空时） |

### 列映射

| A表列 | → | B表列 | 说明 |
|--------|:--:|------|------|
| C(HaploX编号) | → | B(文库编号) | 见优先级 |
| J(预分配数据量G) | → | D(数据量G) | 直接取值（PE150 无系数） |
| 池文库 J列求和 | → | D | 合并格内所有行 J 列求和 |
| H(文库类型) | → | G(文库类型) | |
| L(客户单位) | → | H(客户单位) | |
| M(备注) | → | L(备注) | |

**去重**：B列相同文库编号保留首行，后续丢弃。空文库编号跳过。

## 步骤二：查找填充（C表/D表 → B表）

**脚本：** `step2_lookup.py`

**操作对象：** 所有数据 sheet

### 匹配路由

| B列前缀 | 匹配源 | 匹配方式 |
|------|------|------|
| `HGC-Lib-` 或 `HGC-POOL-` | C表 | F列(HGC编号) 精确匹配 |
| 其他 | D表 | D列(样本编号) 匹配，未匹配再尝试 C表文库名称匹配 |

### HGC 类型（C表匹配）

C 表通过表头文本自动定位列，搜索所有 sheet：

| C表表头 | → | B表列 |
|------|:--:|------|
| Qubit浓度 | → | C + N |
| 文库结构 | → | O |
| 磷酸化* | → | P |
| 环化* | → | Q |
| 板号 | → | K |
| 平均片段 | → | M |

### 非HGC 类型（D表匹配）

D 表通过表头文本自动定位列：

| D表表头 | → | B表列 |
|------|:--:|------|
| Qubit浓度 | → | C + N |
| 结果评价 | → | O |
| 版号 | → | K |
| 孔位 | → | J |
| 平均片段 | → | M |

### 人工检测结果 & 人工备注

所有数据行（不论 HGC/非HGC）独立执行：B列 → C表 F列匹配，成功则回填：

| C表列 | → | B表列 |
|:--:|:--:|------|
| Z(26) | → | R(18) 人工检测结果 |
| AA(27) | → | S(19) 人工备注 |

> 使用固定列号（不依赖表头文本），仅数据 sheet 生效。

## 步骤三：分组与排序

**脚本：** `step3_group_sort.py`

**操作对象：** 所有数据 sheet

### 1. 大类判断

| 条件 | 分类 | 位置 |
|------|------|:--:|
| G 或 O 含"华大"，或 P="已磷酸化" | 直接环化文库 | 后面 |
| 其他 | 转化文库 | 前面 |

### 2. 分组规则

- 按（客户单位 H + 文库类型 G）聚合
- 池文库（`HGC-POOL-` 开头）与普通库（`HGC-Lib-` 开头）分列处理

**特殊合并**：
- 广州基迪奥科技服务有限公司 = 广州奥智生物科技有限公司
- G 列为 `XXX-T7` 视为同类

### 3. D_sum > 1000 均匀拆分

组内 D列总和 > 1000 → 按行数均匀拆为 N = ceil(D_sum/1000) 个子组，每子组 D合计 ≤ 1000。

> 例：9行×120G=1080G → 5行+4行（非 8+1）

### 4. 组内排序

每组内部按 **B列（文库编号）** 升序。

### 5. 写入规则

- 大类间空1行，组间空1行
- E列标注分类："转化文库" / "直接环化文库"（供步骤四）

## 步骤四：公式计算、重分组、汇总行

**脚本：** `step4_formula.py`

**操作对象：** 所有数据 sheet

### 摩尔质量判断

| 类型 | 默认 | 降级条件 |
|------|:--:|------|
| 转化文库 | 50 nM | 组内任一行 N列 < 2.6 → 降为 **10 nM** |
| 直接环化文库 | 300 ng | 固定值 |

### 组排序

写入前排序：**10nM 组** → 50nM → 300ng（直接环化），低浓度组优先展示。

### E列公式

```
=ROUND(D/SUM(D范围)*IF(C="",50,MM),3)
```

- C列有值 → 使用组 MM（10/50/300）
- C列为空 → 强制使用 **50**

### F列公式

```
=ROUND(E/C*G汇总,3)
```

### 重分组

触发条件（任一满足即触发）：D_sum > 1000 **或** F列 max/min > 5

- 按 F 升序 → 以 max/min>5 为界切分
- 子组内 B列升序 → 重新计算 E/F

### 体积调整

| 条件 | 阈值 | 放大规则 |
|------|:--:|------|
| 有板号 | F < 1 | min×N > 1 |
| 无板号 | F < 0.250 | min×N > 0.500 |

缩放倍数 N 写入汇总行 G 列。

### 汇总行

| 列 | 内容 | 说明 |
|:--:|------|------|
| B | 数据条数 | 该组文库数量（静态值） |
| D | `=ROUND(SUM(D范围),2)` | 组总数据量 |
| E | `=ROUND(SUM(E范围),3)` | 组总摩尔质量（公式） |
| F | `=IF(G>1,ROUND(SUM/G×2,3),ROUND(SUM,3))` | |
| G | 缩放倍数 N | 静态值 |
| I | `=ROUND(20-F,3)` 或 `=ROUND(40-F,3)` | 浅蓝背景 |
| M | `=AVERAGE(M范围)` | |

## 步骤五：Lane 编号、颜色标记、文库环化

**脚本：** `step5_lane.py`

**操作对象：** 数据 sheet + 文库环化 sheet

### 数据 sheet

- **A列 Lane 编号**：`{sheet字母}{组序号}`（B1,B2…C1…D1…）
- **A列合并**：同组数据行合并
- **框线**：数据行 A~K列（汇总行不加）
- **10nM 黄色标记**：E列公式含 `10.0` 且本行 C列非空 → A列（合并格）填充黄色 `#FFFF00`
- **直接环化红色标记**：A列填充红色
- **板号交替蓝色**：同板号前缀交替（K列）

> 黄色判定在 step5 执行：先合并 A列，再检测组内任意行 C>0 → 合并格填黄色。

### 文库环化 sheet

每组一行，汇总各 lane。字母变化处空一行。

| 列 | 内容 | 公式 |
|:--:|------|------|
| A | Lane编号 | 从数据 sheet 汇总 |
| B/C | 留空 | 用户手工填入 |
| D | | `=IF(C="","",C×0.66×1)` |
| E | 数据量 | 组内 D列求和（静态） |
| F | | `=IF(B="","",D)` |
| G | | `=IF(B="","",F/B)` |
| H/I | 文库类型/客户单位 | 组内第一行 |
| J | | `=IF(G="","",40-G)` |
| K/L | 留空 | |
| M | | `=IF(OR(L="",F=""),"",22×L/F)` |

## 步骤六：T7+制备

**脚本：** `step6_t7_prepare.py`

从文库环化 sheet 读取数据，填入 T7+制备。

### 数据传递

| 文库环化 | → | T7+制备 |
|---------|---|------|
| A(lane编号) | → | B(文库ssDNA编号) |
| E(数据量) | → | H(数据量G) |
| H(文库类型) | → | N(文库类型) |
| I(客户单位) | → | O(客户单位) |

### A列 laneID

格式 `MMDD + Lane首字母`（当天日期），如 `0806B`。相同 laneID 为一组。

### 用户手工填入列

| 列 | 说明 |
|:--:|------|
| C | SSDNA浓度 |
| D | 平均片段(bp) |
| J | 调整比例 |

### 自动公式

| 列 | 公式/逻辑 |
|:--:|------|
| E | D与中位值比较 → "正常"/"偏大Xbp"/"偏小Xbp" |
| F | `=D×0.33×G×0.001` |
| G | `=900×L` |
| I | `=ROUND(H/H总,4)` |
| K | `=I×J` |
| L | `=K/K总` |
| M | `=F/C` |
| Q | `=I×J` |

### 汇总行（每组末行）

| 列 | 公式 |
|:--:|------|
| D | `=MEDIAN(D范围)` |
| H | `=SUM(H范围)` |
| K | `=SUM(K范围)` |
| M | `=SUM(M范围)` |
| P | `=96-M汇总` |

## 步骤七：下机数据统计模版

**脚本：** `step7_offline_stats.py`

从 T7+制备 sheet **逐行复制**（不去重）到「下机数据统计模版」sheet。

### 数据来源

| 模版列 | T7+制备列 | 操作 |
|:--:|------|------|
| B(Lane_Number) | A(laneID) | 提取末字母 |
| D(文库总数) | B(ssDNA编号) | 查数据 sheet 汇总行 B列 |
| E(文库类型) | N | 直接复制 |
| F(客户单位) | O | 直接复制 |
| G(需求数据量) | H | 直接复制 |
| I(欠缺数据量) | — | 公式 `=H-G` |
| J(数据量补测率) | — | 公式 `=IF(G=0,"",I/G)` |
| K(上机模式) | — | 固定填 `PE150` |

### 文库总数查找

T7+制备 B列 ssDNA编号（如 `B1`）→ 数据 sheet B，按汇总行序号匹配组，读取该组汇总行 B列（数据条数）。

### 合并单元格

A/B/C/K 列按 lane 分组合并。

### 列状态

| 列 | 状态 |
|:--:|------|
| A(FlowCell_ID) | 留空 |
| C(单lane产出) | 留空（下机后填） |
| H(产出数据量) | 留空（下机后填） |
| L(调整比例) | 留空 |
| M(操作人员) | 留空 |
| N(分析原因) | 留空 |

## 步骤八：格式化

**脚本：** `format_font.py`

### 全局格式（apply_standard_format）

| 项目 | 设置 |
|------|------|
| 字体 | Times New Roman 10pt |
| Sheet 顺序 | 数据 sheet(字母序) → 文库环化 → T7+制备 → 下机数据统计模版 → B1-B3 |
| 数据 sheet 表头行高 | 90 |
| 文库环化/T7+制备表头行高 | 40 |
| 下机数据统计模版表头行高 | 40 |
| 所有数据行行高 | 30 |
| D列数字格式 | `0.00` |
| E/F/I列数字格式 | `0.000` |
| 列宽 | 自动适应（上限60） |

### T7+制备 专属

| 列 | 格式 |
|:--:|------|
| H(数据量G) | `0.00` 两位小数 |

### 下机数据统计模版 专属

| 项目 | 设置 |
|------|------|
| D列 | `0` 整数 |
| G/H/I列 | `0.00` 两位小数 |
| J列 | `0.00%` 百分比 |
| A-N列 | 全部框线 + Times New Roman 字体 |
| I列 < 0 | 浅红色填充 `#FFE0E0`（条件格式） |
| J列 < 0 | 浅红色填充 `#FFE0E0`（条件格式） |
