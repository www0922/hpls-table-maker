## 输出文件命名

- Pooling 表：`{当天日期}文库pooling表AE0.xlsx`（例：`20260806文库pooling表AE0.xlsx`）
- PCR 表：`{当天日期}PCR定量表真迈.xlsx`（例：`20260806PCR定量表真迈.xlsx`）

## 输出子表顺序

Pooling 工作簿按以下顺序排列：
1. 数据面（B / A / C / D，按字母排序，动态创建）
2. 文库稀释计算表
3. 下机数据统计模版

## 步骤0：clear_pooling.py

### Pooling 表
- 每次运行从模板全新复制（`reset_output`）
- 根据 A表 sheet 名动态创建对应数据面（A→A面, B→B面, C→C面, D→D面）
- A表没有的 sheet 自动删除（如 A表仅含 B，则 Pooling 只保留 B 面）
- 清空第2行起数据并重置所有样式

### PCR 表
- 清空第6行起数据（DATA_START=6）
- 保护公式列（以 `=` 开头的单元格不清除）

## 步骤1：step1_migrate.py

### Sheet 映射
A表 sheet A → Pooling A面，A表 sheet B → Pooling B面（以此类推）

### 文库编号 (→ B列, col 2)
优先级：B/C列合并格父值 > C列(HaploX编号) > D列(样本名称)

### 合并格处理
- 扫描 B列 和 C列 合并格
- C列仅处理含 `POOL` 的合并格
- 获取合并格首行信息

### 列映射

| A表 | → | Pooling列 | 说明 |
|-----|---|:--:|------|
| H(8) | → | H(8) | 文库类型 |
| K(11) | → | Q(17) | 合同编号 |
| L(12) | → | R(18) | 客户单位 |
| M(13) | → | S(19) | 备注 |
| O(15) | → | T(20) | laneID |

### 数据量 (→ D列, col 4)
合并格范围内 J列(10)求和，否则取 J列值

### 去重
同 (文库编号, laneID) 组合 → 保留首行

## 步骤2：step2_group_sort.py

### qPCR 预填充
从 qPCR 统计表查文库编号 → P列(16)，供后续分组使用

### 分组规则

**强制单样本（最高优先级）：**
- P列有 qPCR 值
- 文库编号匹配 `\d+P\d+-\d+` 格式（整板合并文库，如 `260805P1-228`）
→ 强制单独成组

**库类型分类：**
- `is_bare_library`：匹配 `HGC-\d`、`\d+E$`、`\d+X$`
- 补充判断：备注含"补测" → 补测标记

**Bare 库分组：** 同 lane 内按 (H列文库类型, 补测标记) 分组，忽略客户和普通备注

**普通库分组：** 按 (文库类型, 客户单位, 备注键) 分组
- 含"补测" → 统一备注键 "补测"
- 含"加急"/"加测" → 视为空备注，与空备注组合并

**组间顺序：** 多文库组在前，单文库组在 lane 最后

### Lane 排序
按 T列(laneID) 数值升序排列

### 写入
- 多文库组：数据行 + 汇总行（B=组大小, D=D合计）
- Lane 之间空1行

## 步骤3：step3_lookup.py

### 文库类型判断
- `HGC-Lib-`/`HGC-POOL-`（大小写不敏感）→ 外包 C表
- 其他 → 自建 D表

### 外包 C表

| C表列 | → | Pooling列 | 条件 |
|:--:|---|:--:|------|
| L(Qubit浓度) | → | C(3) + I(9) | M列为空时 |
| P(Qubit nM) | → | C(3) + I(9) | M列有值时 |
| M(平均片段) | → | K(11) | |
| Z(人工检测) | → | V(22) | |
| AA(人工备注) | → | W(23) | |

### 自建 D表（双索引，优先样本编号）

D表采用双索引结构：
- **样本编号**（col 4/5，优先匹配）：parent 行，代表整个合并文库
- **杂交编号**（col 3，次匹配）：child 行，代表合并文库内的单条

查询顺序：**先样本编号 → 杂交编号**。命中第一个即返回，确保优先采用 parent 行数据。

| D表列 | → | Pooling列 |
|:--:|---|:--:|
| K(Qubit) | → | C(3) |
| N(片段) | → | K(11) |
| O(结果评价) | → | L(12) |
| S(孔位) | → | G(7) |
| T(板号) | → | L(12) 覆盖评价 |

### 纯化标记
纯化表 `1-12月纯化` 子表 G列(合同编号) 匹配 → U(21) 写入"纯化"
> 仅扫描 "1-12月纯化" 子表，其余子表忽略

## 步骤4：step4_formula.py

### E/F 列公式（共享倍数法）

约束条件：
- `0.5 ≤ F ≤ 5`（每条数据取样体积）
- `ΣF > 7`（多文库组总体积约束，单文库组跳过）

### 算法

对每组计算统一倍数 M：
```python
M_low  = max(0.5 × C/D)           # 确保 min(F) ≥ 0.5
M_high = min(5.0 × C/D)           # 确保 max(F) ≤ 5

# 多文库组额外约束
M_low = max(M_low, 7.0 / Σ(D/C))  # 确保 ΣF > 7

# 取可行区间的下界
M = M_low  （M_low ≤ M_high 时可行）
```

### 拆分与重合并
- 同组无统一 M → 拆为单样本处理
- 拆分后同 (H类型, R客户, T laneID) 的单样本全量扫描尝试重新合并
- 合并成功的写入 `(False, rows, M, None)`

### 排序
同 lane 内：多文库组优先，单文库组排在末尾

### 写入公式
- E列：`=ROUND(D{行}×{M}, 3)`（M 保留6位小数）
- F列：`=ROUND(E{行}/C{行}, 3)`
- 多文库组写入汇总行（B=组大小, D=D合计）

## 步骤5：step5_summary.py

### 平均片段
组内 K列(11) 非零值取平均 → 写入组内第一行 O列(15)

### 汇总行公式（仅多文库组）

| 列 | 公式 |
|:--:|------|
| D(4) | `=SUM(D{首}:D{末})` |
| E(5) | `=SUM(E{首}:E{末})` |
| F(6) | `=SUM(F{首}:F{末})` |
| G(7) | `=ROUND(E{汇总}/F{汇总}, 3)` |

### 组浓度与稀释规则

**不稀释：** 直接引用 G 列，M第二行清空
- N列（有片段且非bare库）：不稀释时 `=G{汇总}`
- M列（bare库或无片段）：不稀释时 `=G{汇总}`

**N列稀释（组浓度 > 50）：**
- N第一行：`=G{汇总}/D`（取 D = G/45，使结果在 40~50 之间）
- M第二行：`=F{汇总}×(D-1)`，蓝色填充 `#99CCFF`

**M列稀释（组浓度 > 15）：**
- M第一行：`=G{汇总}/D`（取 D = G/12.5，使结果在 10~15 之间）
- M第二行：`=F{汇总}×(D-1)`，蓝色填充 `#99CCFF`

> M/N列数值格式：`0.00`（保留两位小数）

## 步骤10：step9_qpcr.py

### PCR 定量表

- 子表命名：当天日期 `MMDD`（如 `0807`）
- 单 sheet，不分子表
- 数据从第 6 行开始，序号从 1 开始
- G3 = 最后序号 + 1

### 主体数据（第 6 行起）

| PCR列 | 来源 | 说明 |
|:--:|------|------|
| A(1) | 序号 | 从 1 开始 |
| B(2) | 稀释表 B列 | SampleID |
| C(3) | HGC→A表D列；非HGC→B列 | |
| D(4) | 稀释表/组数据量 | |

### 子表格（主体数据下方，动态定位）

主体数据写完后，空 1 行，动态计算子表格起始行：

```
last_main_row = ws.max_row
blank_row     = last_main_row + 1     # 空行
sub_start     = blank_row + 1         # 子表格表头行
```

每条数据占 **2 行**，对应列纵向合并。

#### 子表格列结构

| 列 | 表头 | 合并 | 内容 | 格式 |
|:--:|------|:--:|------|:--:|
| A | 空 | 2行合并 | 序号（从1开始） | 无框线 |
| C | 样本名称 | 2行合并 | 样本名称 | 框线 |
| D | 浓度 ng/ul | **不合并** | 用户手动填入 | `0.00`，框线 |
| E | 平行检测人 | 2行合并 | `=AVERAGE(D{r},D{r+1})` | `0.00`，框线 |
| F | XCL | 2行合并 | `=STDEV(D{r},D{r+1})` | `0.00`，框线 |
| G | 空 | 2行合并 | `=F/E` | `0.00`，框线 |

#### 说明
- 子表格表头字体：Times New Roman **12pt 加粗**
- D 列两行独立（不合并），供用户填入平行检测的两个浓度值
- E 列自动计算两浓度平均值，F 列计算标准差，G 列计算 CV 值
- 子表格不参与 B/H 列黄色条件格式
